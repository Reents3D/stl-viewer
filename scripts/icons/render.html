Symbole der Chrome-Erweiterung erzeugen

Der Chrome Web Store nimmt fuer Symbole nur Rasterbilder an, kein SVG. Diese Seite rastert die Bildmarke aus public/brand/reents-mark-square.svg in den vier geforderten Groessen. Die Dateien gehoeren nach extension/icons/ und liegen dort im Git — sie werden nicht bei jedem Bau neu erzeugt, sondern nur, wenn sich die Bildmarke aendert.

So aufrufen: einen statischen Server auf dem Projektstamm starten (python -m http.server 8090) und http://localhost:8090/scripts/icons/render.html oeffnen. Direkt aus dem Dateisystem geoeffnet verweigert der Browser das Auslesen der Zeichenflaeche — eine per file:// geladene Grafik gilt als fremde Herkunft und macht die Zeichenflaeche unlesbar.
