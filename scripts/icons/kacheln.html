Werbekacheln fuer den Chrome Web Store

Zwei Groessen: die kleine Kachel 440 x 280 (empfohlen, erscheint in Uebersichten) und die grosse 1400 x 560 (freiwillig, noetig fuer redaktionelle Platzierungen). Der Store verlangt JPEG oder 24-Bit-PNG ohne Alpha; die Zeichenflaeche liefert RGBA, deshalb laeuft danach scripts/store-bild.mjs darueber.

Bewusst ohne Bildschirmfoto darin. Eine Werbekachel ist eine Markenflaeche, kein Schaufenster: In der Uebersicht steht sie klein neben vielen anderen, und ein hineinkopierter Programmausschnitt wird dort zu Brei. Was wirkt, sind Zeichen, ein Wort und eine Aussage.

Aufrufen ueber einen statischen Server auf dem Projektstamm (python -m http.server 8090), dann /scripts/icons/kacheln.html.
